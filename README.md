# 🎮 MORAXGAME - The Return

> Um jogo desenvolvido em **Godot Engine** utilizando **C#**.

---

## 📖 Sobre o Projeto

### 📝 O que é o jogo?

> *Um jogo estilo Vampire Survivors desenvolvido para aprender a ferramenta e a linmguagem de programação C#*

### 🎯 Objetivo

Sobreviva ao máximo de tempo possível enquanto ondas de inimigos se aproximam. Suba de Nível para ficar vivo por mais tempo!

---

## 🛠️ Tecnologias

* 🎮 **Godot Engine**
* 💻 **C#**
* 🧩 **.NET**
* 🗃️ **Git / GitHub**

---

## 💻 Requisitos

Antes de executar o projeto, certifique-se de ter instalado:

* [Godot Engine](https://godotengine.org/)
* **.NET SDK**
* **Git** (opcional, caso utilize o repositório via Git)

> ⚠️ **Importante:** Para projetos Godot com C#, é necessário utilizar a versão do Godot que possui suporte ao **.NET**.

---

# 🚀 Instalação e Configuração

## 1. 📥 Instalar o Godot

Baixe a versão do Godot com suporte a **.NET/C#** através do site oficial:

https://godotengine.org/download/

Após o download, instale ou extraia o Godot de acordo com o seu sistema operacional.

---

## 2. 💻 Instalar o .NET SDK

Baixe e instale o **.NET SDK** pelo site oficial da Microsoft:

https://dotnet.microsoft.com/download

Após a instalação, abra um terminal e execute:

```bash
dotnet --version
```

Se uma versão do .NET for exibida, a instalação foi concluída corretamente.

---

## 3. 📦 Clonar o projeto

Clone o repositório utilizando Git:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd NOME_DO_PROJETO
```

Ou, caso tenha baixado o projeto como `.zip`, extraia os arquivos para uma pasta de sua preferência.

---

## 4. 🎮 Abrir o projeto no Godot

Abra o **Godot Engine**.

Na tela inicial:

1. Clique em **Import**
2. Selecione a pasta do projeto
3. Selecione o arquivo:

```text
project.godot
```

4. Clique em **Import & Edit**

O Godot irá carregar o projeto e gerar os arquivos necessários.

---

## 5. 🔄 Restaurar as dependências do C#

Abra um terminal na pasta do projeto e execute:

```bash
dotnet restore
```

Depois, compile o projeto:

```bash
dotnet build
```

Caso não apareçam erros, o ambiente está configurado corretamente.

---

# ▶️ Executando o jogo

Com o projeto aberto no Godot, pressione:

```text
F6
```

para executar a cena atual.

Ou pressione:

```text
F5
```

para executar o projeto inteiro.
